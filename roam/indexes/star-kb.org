* Purpose
Star KB is the shared symbolic reasoning layer used by StarIntel actors and services. Canonical StarIntel JSON remains authoritative; Star KB deterministically projects that corpus into modular Prolog facts and safe reasoning tools.

* Current phase
Research and the Prolog projection/query design are approved. The active bounded implementation is =prolog-star-kb=: canonical JSON -> lossless Prolog facts + semantic indexes + AI reasoning tools.

No bulk real-world ingestion is authorized in this slice.

The no-LLM rewarded symbolic learning / Aleph / active learning / Wolfram direction is *proposed research*, not an approved runtime slice. [[https://github.com/starintel-labs/star-kb/pull/8][Actor learning PR #8]] is a separate, currently unmerged integration dependency; do not duplicate its candidate/admission machinery.

* Roadmap
1. Verify deterministic JSON -> Prolog projection and safe AI tool compiler.
2. Add SWI-Prolog CI smoke coverage.
3. Add query-server transport around the bounded semantic predicates.
4. Generate MCP and Agent2Agent surfaces from the same tool catalog.
5. Add StarLang =kb=, =reason=, and RLM bindings.
6. Add engine adapters chosen by semantic capability.
7. Grow domain semantic indexes without sacrificing lossless generic projection.
8. Only then begin controlled corpus ingestion/materialization.
9. Gate the proposed Aleph induction, human active learning, reward optimizer, canonical document publisher, and optional Wolfram adapter as separate research/design/verification slices. Reuse PR #8 after it is reconciled; do not create a duplicate learning protocol.
