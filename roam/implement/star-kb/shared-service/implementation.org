* Architecture and canonical boundary
Both listeners share authentication, trusted scope, request replay, lifecycle and the actual StarLang Common Lisp SWI adapter at bfba04a15f43215cd323e1dde2d98a7343abb3ea. The fixed relation query consumes bounded data-only rows; it does not expose Prolog source or caller goals.

Directed source relations are returned, not inferred canonical truth. Exact schema, source, bootstrap, executable and generation identities are retained.

* Runtime lessons
A killed Lisp supervisor can orphan its SWI child. Group termination alone did not reap the orphan in the initial experiment. Linux subreaper adoption plus session-scoped pidfd signaling and waitpid resolves the owned descendant; normal EOF lets the existing adapter reap its own worker. Integration tests cover abrupt death, stopped groups, terminal failure and fresh-worker snapshot replay.

A Debian runtime extracted without package post-install hooks needs make_library_index(swi(library)); otherwise MQI fails resolving uuid:option/3. This is environment setup, not an upstream adapter defect. No StarLang process-drain race fix was duplicated.

* Ingress review correction
Independent review identified unauthenticated HTTP body waiting and progress-reset socket timeouts. Both were reproduced against the pre-fix tree. HTTP now authenticates before waiting on body bytes and uses an absolute two-second header/body read deadline with bounded serving concurrency. ZMQ transport authentication precedes application payloads; multipart is not drained, and the listener is recycled within a deadline. Six bounded real-socket security fixtures are distinct from ten real-SWI integration tests. Local full regression: 116 tests passed. Exact-head CI and independent re-review remain required before any merge.

ZMQ PLAIN is loopback-only and is not encryption. libzmq can buffer authenticated multipart input before Python receives it, so an aggregate native-memory cap is not claimed; hostile remote multi-tenant exposure still requires native-worker memory isolation.

* Verification and remaining gates
Local real service suite: 10 tests cover the reaping fix, query bounds and admission budgets. Repository tests and exact-head CI evidence are recorded in the PR and service evidence note. No skipped or mock adapter test is counted as real integration.

Still open: generated actor/service wire binding, encrypted remote listeners, in-flight cancellation, canonical durable derived-document write/readback, proactive bounded expert agenda, RabbitMQ, and multi-node storage/partition/replay/convergence. The distributed node/placement/consistency proposal is explicit in the service contract, not an implementation claim. NLP classifications remain later scope.
